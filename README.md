# Ozon Card Checker

Локальное веб-приложение для ручной проверки карточек товара по загруженной базе правил. База хранится в SQLite, а изображения не сохраняются в журнале проверок.

## Запуск

В PowerShell из папки проекта:

```powershell
& 'C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' .\app.py
```

Откройте `http://127.0.0.1:8080`.

## LLM-проверка

Без настроек приложение выполняет только строгие, формализованные проверки и возвращает «Требуется проверка», если нарушения не выявлены. Для проверки текста и одного изображения задайте переменные окружения совместимого с OpenAI API провайдера:

```powershell
$env:LLM_API_KEY = 'ваш_ключ'
$env:LLM_MODEL = 'модель_с_поддержкой_изображений'
$env:LLM_BASE_URL = 'https://api.openai.com/v1'
& 'C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' .\app.py
```

`LLM_BASE_URL` можно не задавать для стандартного адреса. API-ключ хранится только в переменной среды и не записывается в SQLite.

## Данные

- `data/ozon_rules_source_base.json` — исходные DOCX/PDF, извлечённые с указателями на фрагменты.
- `data/ozon_checker.sqlite3` — создаётся при первом запуске: правила, фрагменты источников и история проверок.
- `CORE_RULES` в `app.py` — начальный нормализованный слой наиболее важных карточечных правил, включая принципы честной конкуренции.
